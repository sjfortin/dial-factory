# FI-001: Validate invalidation and recovery, not just happy paths

Status: implemented in 3652c7e and independently accepted by review-2.json and verify-2.json.

Problem: the first scaffold passed its six tests but independent Review found that prior evidence could outlive a failed rerun, a revision, or a specification change. Interrupted handoff writes could also leave required artifacts missing at completion.

Evidence: FACTORY-BOOTSTRAP candidate 027fdad, review-1.json; four independent reproductions in the review report. No human intervention was needed to identify or route these defects.

Proposed improvement: use these four cases as explicit regression checks in the factory test suite and behavioral verification packet. Treat latest run, current attempt, exact approved specification content, and complete handoff artifacts as separate conditions. Preserve failing evidence and rerun the same workers after correction.

Success measure: independent Review and Verify confirm each reproduction is rejected or recovered correctly on the replacement candidate. These tests are synthetic factory fixtures, not Dial playback evidence.

This proposal does not silently change production rules. The approved bootstrap contract already requires these conditions; implementation changes remain subject to independent review.

# Implement

Only this role edits production code. Follow the approved Spec or recorded skip and acceptance criteria. Commit each candidate so Review and Verify can bind evidence to a Git commit. Report `work_item`, `run_id`, `agent`, `change_summary`, `decisions`, `candidate_commit`, `tests` with actual evidence, `ambiguities`, and `blockers`. Never approve/review/verify your own candidate. On revision, create a new candidate and preserve the prior attempt.

# Review

Use an identity different from Implement. Inspect the exact candidate commit and approved criteria read-only. Report `work_item`, `run_id`, `agent`, `candidate_commit`, `attempt`, `requirements`, `architecture`, `correctness`, `tests`, `security`, `complexity`, `findings` (list), and `recommendation` (`ACCEPT`, `REVISE`, `HUMAN_DECISION`). Findings should locate defects and explain impact. Do not edit production code or silently approve an ambiguous requirement.
